# まなびゲーム箱

中学受験向けの学習ゲームを集めたサイトです。`games` フォルダにゲームのファイルを入れると、トップページの一覧が自動で更新されます。

## フォルダのしくみ

```
manabi-games/
├─ index.html・parent.html・buy.html・plan.html・privacy.html・tokushoho.html（サイトの土台）
├─ site.json（サイトの名前・料金サーバーのアドレスなどの設定）
├─ games/
│   ├─ sansu/   算数
│   ├─ kokugo/  国語
│   ├─ rika/    理科
│   ├─ shakai/  社会
│   └─ shikou/  思考力
├─ scripts/（サイトを組み立てるプログラム。さわらない）
├─ server/（有料プランのサーバー。説明は server/SETUP.md）
└─ .github/workflows/pages.yml（自動で公開するための設定。さわらない）
```

ファイルを入れたり直したりすると、GitHub Actions が自動でサイトを組み立てて公開します（1〜2分）。公開されたアドレスは `https://manabigamebako.com/` です（独自ドメイン。もとの `https://ユーザー名.github.io/manabi-games/` は自動でこちらに転送されます）。

## ゲームを追加するとき

ゲームのHTMLファイルを、その教科のフォルダ（例：算数なら `games/sansu`）に入れます。一覧には自動で並びます。

ゲームの教科と単元は、ファイルの先頭にある次の行で決まります（Claudeに作ってもらうときは「サイト用の情報も入れて」と頼めば入ります）。

```html
<meta name="game:subject" content="算数">
<meta name="game:unit" content="図形">
<meta name="game:grade" content="小4〜">
<meta name="game:players" content="1人">
<meta name="description" content="一覧に出る説明文">
```

この行がない場合は、フォルダの名前で分類されます。

## 中高一貫コースのゲームを追加するとき

中高一貫校の中学生向けのゲームは、`games/chuko/教科/単元/` に入れます（例 `games/chuko/数学/正負の数/seifu.html`）。このフォルダに入れると、中学受験のトップには出ず、`chuko/index.html`（中高一貫コース）の一覧に出ます。教科の名前は「数学」「英語」「国語」など中学の名前にします。

- ファイル名は、中学受験のゲームと重ならない名前にします（保護者ページの記録はファイル名で分けるため）。
- 有料版は `server/worker.js` の GAMES に `"ゲーム名": "chuko"` と書きます。中高一貫コースの有料版は「中高一貫コース」のプランだけで使えます（「全教科」では使えません）。
- 継続割引の割合は `server/worker.js` の `CONTINUE_OFF`（0 で割引なし）、値段は `PRICES.chuko` で変えます。

## ゲームを消す・直すとき

`games` の中の教科のフォルダでファイルを開き、右上の「…」から **Delete file** で消せます。直したファイルは同じ名前でアップロードし直せば置きかわります。

## サイトの名前や教科の並び順を変えるとき

`site.json` を開き、えんぴつのマークで編集します。

- `name`：サイトの名前
- `description`：トップページの説明文
- `subjectOrder`：教科を並べる順番

## Google アナリティクスで遊ばれ方を見る

### 設定（1回だけ）

1. [Google アナリティクス](https://analytics.google.com/)にGoogleアカウントでログインし、「測定を開始」からアカウントとプロパティを作ります。
2. 「データストリーム」で **ウェブ** を選び、サイトのアドレス（`https://ユーザー名.github.io/リポジトリ名/`）を入れます。
3. 表示される **測定ID**（`G-` で始まる文字）をコピーします。
4. GitHubで `site.json` を開き、えんぴつのマークで次のように書きかえて保存します。
   ```json
   "gaMeasurementId": "G-XXXXXXXXXX",
   "contact": "お問い合わせ用のメールアドレスなど",
   ```
5. 1〜2分で、すべてのページで計測が始まります。新しく追加したゲームも自動で計測されます。

### 記録されること

| 記録の名前 | いつ記録されるか | 分かること |
|---|---|---|
| `page_view` | ページを開いたとき | どのゲームが何回開かれたか |
| `level_start` | ゲームや分野を始めたとき | 実際に遊び始めた回数 |
| `level_end` | 最後まで遊んだとき（点数つき） | 最後まで遊んだ割合、点数 |
| `answer_question` | 問題に答えたとき（正解・不正解つき） | どの分野・問題でまちがえやすいか |
| `net_found` | 展開図パズルで新しい形を見つけたとき | どこまで集めたか |

すべての記録に `game_title`（ゲームの名前）がつきます。

### 見るときのコツ

- 数は「レポート」→「エンゲージメント」→「イベント」で見られます。
- 正解・不正解や分野ごとに分けて見たいときは、「管理」→「カスタム定義」で `game_title`・`category`・`correct`・`question`・`score` を**イベントスコープのカスタムディメンション**として登録してください。登録した日以降のデータが分けて見られるようになります。
- 数字はダウンロードしてClaudeに渡せば、どのゲームを有料版にするとよいかの分析ができます。

※ プライバシーポリシー（`privacy.html`）のひな形を入れています。法律の専門家の確認を受けたものではないので、有料版の販売を始める前などに内容を見直してください。

## 有料版と料金プラン（利用コード）

有料版は、教科（国語・算数・理科・社会・思考力・全教科）と利用期間（1日・1週間・1ヵ月・1年）をえらんで買う「買い切り」です。購入すると **利用コード**（`MN-XXXX-XXXX-XXXX`）が出て、そのコードを入れた端末で、期間中だけ使えます。

- 料金プランのページ：`buy.html`（一覧の上の「料金プラン」）
- 利用中のプラン・利用コードの入力：`plan.html`
- 特定商取引法に基づく表記：`tokushoho.html`（`site.json` の `seller` に販売者の情報を書きます）

支払いは Stripe、利用コードの確認と問題データの配信は Cloudflare Workers で行います。始め方は **`server/SETUP.md`** を見てください。`site.json` の `apiBase` が空のあいだは、有料版は「販売準備中」と表示されます。

### 大事なこと

- **有料版の問題データ（packs フォルダ、`*-source.json`）は、GitHubにアップロードしないでください。** サーバー（Cloudflare）にだけ入れます。
- **問題を直したとき**は、直したデータを `server/admin.html` で入れ直すだけです。サイトを公開し直す必要はありません。
- **有料版のゲームを新しく作ったとき**は、`server/worker.js` の `GAMES` にゲーム名（ファイル名から `-full.html` を取ったもの）と教科を足して、デプロイします。

## 保護者ページ（学習の記録）

- `parent.html` が保護者ページです。一覧ページの下にリンクがあります。
- ゲームで遊ぶと、日時・コース・点数・まちがえた問題が、その端末のブラウザの中（`mn-history`）に自動で記録されます。どこにも送られません。
- 記録のしくみは `scripts/build.mjs` がすべてのゲームに自動で入れます。新しいゲームでも、`mnTrack('level_start' / 'answer_question' / 'level_end')` を呼んでいれば記録されます。
- 有料版の「覚えた・にがて」は、各ゲームの記録を読んで表示します。新しい有料版を作ったら、`parent.html` の `REC` に「保存キー・ファイル名・問題数」を1行足してください。
- 記録が見られるのは、子どもが遊んだのと同じ端末・同じブラウザだけです。

## ご意見フォーム・問題のお知らせ・ワンタップ評価

全ゲームの右下に「ご意見」ボタン、ゲームを1回終えたときに「このゲーム、どうだった？」の評価が出ます（`scripts/feedback.html` を build.mjs が自動で入れます）。

### Googleフォームのつなぎ方（最初に1回だけ）
1. Googleフォームを新しく作り、次の質問を作ります（質問名は自由ですが、選択肢の文字は正確に）。
   - 種類（ラジオボタン）：選択肢を「感想・ご意見」「問題のまちがい」の2つにする
   - ゲーム名（記述式）
   - 問題（記述式）
   - そのほかは自由（むずかしさ・おもしろさ・お子さんの学年・ご意見・返信先メール〈任意〉など）
2. 右上の「︙」→「事前入力したURLを取得」を開き、種類は「感想・ご意見」をえらび、ゲーム名に `GAME`、問題に `QUESTION` と半角で入れて「リンクを取得」→「リンクをコピー」。
3. コピーしたURL（docs.google.com で始まる長いURL）を、site.json の `"feedbackForm"` に貼ります。
4. GitHubに上げると、全ゲームに「ご意見」ボタンが出ます。`feedbackForm` が空のあいだはボタンは出ません。

問題の画面で「ご意見」→「いまの問題のまちがいを知らせる」を押すと、ゲーム名と直前に答えた問題が入った状態でフォームが開きます。

### 評価の見方（Google アナリティクス）
- イベント名 `game_rating`、パラメータ `rating`（fun＝たのしかった／ok＝ふつう／hard＝むずかしすぎた）と `game_title` で届きます。
- アナリティクスの「管理」→「カスタム定義」で、`rating` と `game_title` をイベントスコープのカスタムディメンションとして登録すると、レポートでゲームごとの内訳が見られます（登録した日以降のデータから集計されます）。
- 同じゲームの評価は、1台の端末で1日1回までしか出ません。
