まなびゲーム箱 管理画面

このファイルはGitHubに入れず、自分のパソコンだけで使ってください。管理キーは、このパソコンのブラウザにだけ保存されます。

1. サーバーとの接続



  
2. 有料版の問題データを入れる

    
packs フォルダの JSON ファイルをまとめてえらびます（ファイル名＝ゲーム名、例 chusho.json）。問題を直したときも、同じようにえらび直せば上書きされます。

    
    


  
3. 利用コードを作る（テスト・プレゼント・おわび用）

    

    

    
    

    
まとめて作る（チラシ用）

    
上の教科・期間・メモで、指定した数の利用コードを作り、一覧をExcelで開けるファイル（CSV）で保存します。この一覧を、チラシ印刷（flyer.html）で読み込めます。

    

    


  
4. 利用コードを調べる・変える

    
    

    

    

    

    
状態：unused＝まだ使われていない、active＝利用中、expired＝期間終了、revoked＝使えなくした。日時は「〜時点」のミリ秒で、下に日本時間でも表示します。

  
5. お問い合わせ

    
お問い合わせフォーム（contact.html）から届いたものです。新しい順に並びます。返信は、書かれた返信先のメールアドレスに、ふだんのメールで送ってください。

    

    

    

  
6. 緊急のお知らせ（全ページの上に帯で出す）

    
「出す」を押すと、すぐにサイトの全ページ（ゲームの中もふくむ）の上に帯が出ます。見た人は「×」で閉じられます。新しいお知らせを出すと、閉じた人にもまた出ます。ふつうのお知らせ（新しいゲームなど）は、ここではなく「お知らせ」ページに書きます。
